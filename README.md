# vivaui/homebrew-tap

Package-manager manifests for the [`viva`](https://github.com/vivaui/viva) command,
which builds, packages and live-reloads Viva desktop applications.

These files are generated by the release workflow of
[vivaui/viva](https://github.com/vivaui/viva) from the published archives and their
SHA-256 digests; do not edit them by hand.

## Homebrew (macOS, Linux)

```sh
brew install vivaui/tap/viva
```

## Scoop (Windows)

```sh
scoop bucket add vivaui https://github.com/vivaui/homebrew-tap
scoop install viva
```

Packages are available from the first release that carries prebuilt archives
(`v0.1.3`). Before that, install with `go install github.com/vivaui/viva/cmd/viva@latest`.
